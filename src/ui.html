First time here? Open for the two steps to get started.

1 Start the relay

In the cloned project folder, with Node.js 24+ and pnpm installed:

pnpm install --frozen-lockfile
pnpm run socket

Leave the terminal running.

2 Add your MCP server

Paste this into your client's MCP config. In Cursor, use ~/.cursor/mcp.json.

Reload MCP servers, then connect in the Connection tab.

Read, export and edit the open file. No Figma API token required. Guide on GitHub
